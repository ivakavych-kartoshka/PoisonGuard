# Result Integrity Audit

- **Paper-level experiments run:** No. No attack/baseline harness, ASR evaluation, utility evaluation, rollback benchmark, or external-power energy measurement was executed for a paper table.
- **Measured non-pilot artifacts:** Normalized real datasets were provisioned locally; a five-step and a three-run Xiaomi 13T system microbenchmark were executed. Both are labelled `not a paper result`.
- **Output status:** Every artifact under `outputs/` is synthetic, a policy simulation, or a labelled system microbenchmark; none is a paper result.
- **Paper placeholders:** No empty paper table cell or conceptual curve was replaced, copied, inferred, or treated as measured evidence.
- **Plot status:** `metrics.png` is a synthetic policy-rate plot generated by `plot_results.py` from `results.json`; its title states its status.
- **Table status:** No hard-coded result table is shipped. JSON numbers are computed by the configured deterministic vector harness.

## Real protocol and aggregation gates

- `configs/real_experiment_template.yaml` requires explicit paths/commands for trainer, attacks, baselines, telemetry, and measured result files. Missing pins raise `RealExperimentNotReady` or `ExternalDependencyUnavailable`.
- `poisonguard real --stage run` writes immutable input, attack, baseline, trainer, telemetry, and run manifests. It computes no ASR, utility, rollback, or systems metric.
- `poisonguard real --stage aggregate` reads only explicitly configured measured result files. Missing fields stay missing unless listed in `metrics.required_fields`, in which case loading fails.
- `energy_j_external` is populated only when a measured file declares `energy.source: external_power_monitor`. Android counter values are kept in `energy_j_android_secondary` and excluded from energy claims.
- External wrappers validate repository provenance and never emulate a published attack or baseline. Repositories are pinned by commit; executable adapter commands remain empty, so no published implementation has been run.
