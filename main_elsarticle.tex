\section*{Highlights}
\begin{itemize}
  \item Defines cross-sink laundering from mobile memory records into personalized LoRA weights.
  \item Carries OS-visible provenance through selection, memory, training windows, and checkpoints.
  \item Quarantines candidate adapters and restores clean state by lineage rollback-and-replay.
  \item Proves sufficient-condition non-laundering, restoration, and systems-cost bounds.
  \item Specifies a reproducible phone evaluation without presenting placeholder values as results.
\end{itemize}
