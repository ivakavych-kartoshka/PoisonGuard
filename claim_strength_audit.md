# Claim Strength Audit

| Term/claim | Decision | Rationale |
|---|---|---|
| “first on-device multi-channel poisoning study” | removed | Exhaustive novelty cannot be established from the verified search. |
| “exact rollback” | retained conditionally | Theorem 2 states explicit deterministic, versioned, retained-data premises. |
| “no causal influence remains” | narrowed | Applies only to identified revoked roots and registered transitions. |
| “optimal” | removed | No optimality proof. |
| “sharp threshold” | removed | No matching upper/lower threshold result. |
| “matching impossibility” | removed | No lower bound under the same model. |
| “state-of-the-art/superior” | removed | No measured results. |
| “no utility loss” | removed | Utility must be measured with equivalence margins. |
| “unlearning fails” | scoped | Attributed to the empirical settings studied by Pawelczyk et al.; not universalized. |
| “trusted user text” | weakened | Called verified user-authored input; social engineering remains explicit. |
| “federated defenses do not work” | narrowed | They are structurally inapplicable to a single-device setting; one recent result is cited only for its own federated model. |
| “bounded influence” | retained conditionally | Parameter displacement only, under clipping and nonexpansiveness; not an ASR bound. |
