Phones increasingly maintain persistent language-model state: retrieved memories, user profiles, and locally trained low-rank adapters. Their training signal arrives through channels with sharply different trust---typed text, received messages, notifications, calendar invitations, shared files, clipboard content, and screenshot indexes---yet current personalization pipelines commonly discard that origin before selecting data for learning. This creates \emph{cross-sink laundering}: an untrusted item first enters memory, is later selected for adapter fine-tuning, and continues to control model behavior after the source and memory record are deleted. We present \PG, a provenance-carried personalization design for single-device small language models (SLMs). PoisonGuard attaches an OS-visible provenance envelope to every candidate event, applies an explicit admission policy independently to memory and parameter updates, trains LoRA adapters in quarantine, and records a shared lineage graph from sources through derived memories and training windows to promoted checkpoints. When an item is later judged malicious, PoisonGuard invalidates all reachable state, returns to the last unaffected checkpoint, and deterministically replays admissible events. Under complete mediation, immutable provenance, and versioned deterministic replay, we prove sufficient conditions for non-laundering and exact restoration; we also bound checkpoint storage, replay work, and pre-promotion contaminated influence. The guarantees deliberately exclude compromised operating systems and socially engineered user-authored input. We define a phone-scale evaluation spanning message, notification, calendar, file-share, clipboard, and screenshot channels; memory and LoRA attacks; adaptive retyping; clean personalization utility; false quarantine; and storage, energy, and latency costs. Because no device measurements are present in the source project, all result panels are visibly labelled as protocols or placeholders rather than empirical findings. The resulting manuscript turns provenance from passive metadata into an enforceable learning boundary and a precise recovery mechanism for mixed memory-plus-adapter personalization.
